# Assets for the prank
- Put funny pictures (.png, .jpg, .jpeg, .gif, .webp) in `assets/images/`; the app will randomly pop them up.
- Put a background music file named `background.mp3` in `assets/music/`.
- Optional Windows icon: `assets/icon.ico`.
The app is a harmless parody: it does not install Windows, alter system files, add startup tasks, or persist after closing.
