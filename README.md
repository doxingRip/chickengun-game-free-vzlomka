# ChickenGun Windows 12 Prank
A harmless Electron joke installer. It plays optional background music and randomly displays images from `assets/images`, while showing a fake “Установка Windows 12” progress bar.

## Run
```bash
npm install
npm start
```
## Build Windows EXE
On Windows:
```bash
npm run build:win
```
Output: `dist/Windows 12 Setup (PRANK) Setup.exe`

## Customize
- Pictures: `assets/images/`
- Music: `assets/music/background.mp3`
- Icon: `assets/icon.ico`

This is only a visual gag. No OS installation, file deletion, registry edits, startup persistence, or other system changes are performed. Close the window any time to stop the music.
